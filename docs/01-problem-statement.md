# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Retail Client
- **Engagement type:** Implementation Delivery

## Business problem

The Retail Client received denormalised One-Big-Table ecommerce Excel extracts and needed a governed Databricks Lakeflow SDP medallion path that splits domains, applies SCD logic, and publishes gold analytics without manual spreadsheet modelling.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
